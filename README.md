# MS Word Cheatsheet

A one-page quick reference for those MS Word features students need most when
writing assignments and dissertations: modifying styles, page and section
breaks, captions, cross-references, tables of contents and page numbers.

Each entry shows the **tab** to open and the **menu path** to follow. The
steps are the same in Word for Windows and Mac (Microsoft 365).
